# Kontor – Downloads

**Kontor** ist eine Buchhaltung für Selbstständige (Einnahmenüberschussrechnung), die auf dem eigenen Computer läuft:
Bankabruf, Belege mit Texterkennung, Abgleich, EÜR, Umsatzsteuer, Rechnungen mit E-Rechnung (ZUGFeRD/XRechnung)
und Ausfüllhilfen für ELSTER. Deine Daten bleiben auf deinem Computer.

Hier liegen nur die fertigen Programmdateien. **Neueste Version:** [Releases → Latest](https://github.com/TimderG/kontor-download/releases/latest)

## Installieren

- **Mac** (Apple-Chip, ab macOS 14.8): `Kontor-…-mac-arm64.dmg` öffnen und Kontor in den Programme-Ordner ziehen.
  Beim ersten Öffnen warnt macOS, weil die App nicht von Apple geprüft ist: Rechtsklick auf Kontor → „Öffnen“.
- **Windows**: `Kontor-…-windows-setup.exe` ausführen.

Eine neue Version installierst du genauso – die alte wird ersetzt, deine Daten bleiben erhalten.
Ab Version 0.1.2 meldet sich Kontor selbst, wenn es eine neue Version gibt.

Die Kurzanleitung (PDF) liegt bei jeder Version dabei.

## Hinweis

Kontor ist eine Hilfe für die eigene Buchhaltung und ersetzt keine Steuerberatung. Nutzung auf eigene Verantwortung.
